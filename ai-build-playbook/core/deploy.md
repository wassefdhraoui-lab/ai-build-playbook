# Deploy

1. Final checks from `quality-checklist.md`.
2. Set environment variables in the host dashboard, never in the repo.
3. Deploy from the GitHub repo (preview deploys for branches, production from `main`).
4. Open the live link in a private window on desktop and phone. Try the core feature.
5. Add the live URL to the README and to the portfolio project data.
6. Tag the release (`v1.0.0`).
