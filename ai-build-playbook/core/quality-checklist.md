# Definition of Done (tick every box or write why not)

## Works
- [ ] Clean clone runs with the commands in the README (`npm ci`, `npm run dev`, `npm run build`)
- [ ] Lint, typecheck, build and tests pass (real output checked)
- [ ] No errors in the browser console
- [ ] The core feature works from the live link, tested in a private window

## Looks and feels right
- [ ] Responsive at 390, 768 and 1440 px
- [ ] Keyboard usable, visible focus, readable contrast, reduced-motion respected
- [ ] Loads fast (target: Lighthouse 90+ for performance, accessibility, best practices, SEO)

## Safe
- [ ] Security checklist in `security.md` passed
- [ ] `npm audit` reviewed
- [ ] No secrets or private data in the repo history

## Explained
- [ ] README: what it is, live demo, how to run, tech, what I learned, known limits
- [ ] 2-3 screenshots or a 30-60 s recording
- [ ] Feedback link works (GitHub issue template or contact link)

## Story
- [ ] `LESSONS_NEW.md` reviewed and merged into the playbook
