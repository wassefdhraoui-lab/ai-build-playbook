# Workflow for one project

| Step | What |
|---|---|
| 1 Brief | Fill `PROJECT_BRIEF.md`: problem, user, one core feature, what "done" means |
| 2 Plan | Agent writes a 5-line plan, you approve |
| 3 Build | Small steps, commit after each |
| 4 Verify | Run `quality-checklist.md` |
| 5 Ship | Deploy, test the live link in a private window (`deploy.md`) |
| 6 Learn | Merge `LESSONS_NEW.md` into the playbook |

## Scope rules
- One core feature only. Write "later" ideas in the brief and leave them out.
- If the build runs past the time box, cut scope instead of extending.

## Definition of a project
Something a stranger can open from a link and use in under 30 seconds, without reading anything first.
